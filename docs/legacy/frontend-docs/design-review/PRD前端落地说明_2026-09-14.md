# PRD 前端落地说明

> 2026-09-14。仓库：E:\Git projects\TS-frontend。

## 使用入口

启动项目（开发服务当前在 localhost:3108），沿用现有登录流程后进入 **产品工程 → PRD生成**。顶栏右侧或账户菜单“外观”可以切换明亮 / 深色模式。

1. 输入自己的功能说明，或点击 AEB 示例；点击自动扩写后直接回填，不会自动发送。
2. 可以继续编辑提示词；点击发送或 Ctrl / ⌘ + Enter。Enter 单独按下为换行。
3. 生成成功立即显示中央 PRD、右侧同一会话，以及工作空间中的待处理对象。生成期间输入的下一条要求不会丢失。
4. 可以编辑整份自由文本，保存仍为待处理，取消不修改原稿。
5. 在回答底部的产物卡片中勾选、接受或放弃。放弃要确认；未接受的 PRD 不可用于 UC。
6. 已接受态只展示 UC 入口解锁和后续接入说明，不生成虚假 UC 数据。
7. 右侧窄输入框同样支持扩写。目录对象仍需勾选后显式“添加到 AI 对话”，支持从输入框移除。
8. “模拟演示 · 选项”可让下一次扩写或生成失败，用于检查错误 / 重试；该选项仅为演示测试辅助。

## 当前边界（不是正式服务承诺）

- 扩写 / 生成为本地模板 + 可取消延时，不调用真实 AI；界面明确标记模拟演示。
- 当前每项目一份 PRD，后续输入完善当前待处理草稿。多 root、多个并行 PRD 和多产物批处理不在本轮实现范围。
- 切换项目 / 模块 / 主题保留当前会话。刷新后清空演示业务数据；只有主题偏好保存在 localStorage，没有存储认证 token。
- 已接受版本的后续编辑暂禁用并说明，等待 P-04 规则；不是最终产品“不可编辑”的结论。
- 放弃后暂保留空功能目录与对话，等待 P-03 规则。保存 / 取消、卡片默认勾选等 P-06/P-07 建议未转为用户已确认规则。
- 预览支持基础标题、段落、列表，不执行用户 HTML，也不强制字段；不是完整 Markdown / 富文本编辑器。
- 真实认证链路保留，未改后端；浏览器测试只在隔离上下文拦截 auth/me 返回测试用户，并非在应用中添加绕过登录。
