### 3.1 下拉细节（设计默认）

1. 点击某行子系统框展开浮层，显示当前 FR 编号，防止误操作其他行。
2. 搜索仅过滤子系统候选，不筛选 FR 表格、不清除已选项。
3. 勾选 / 取消勾选只更新当前 FR 的分配关系；不改变 FR 原文和其他行。
4. 选择即时更新本行；“完成”仅收起浮层，不是页面保存按钮。点击外部 / 关闭亦收起。
5. 当前默认允许取消最后一个子系统，回到“请选择子系统”。正式实现可按业务校验约束调整。
6. 折叠时单选显示名称；多选显示首个名称及“等”，展开后查看完整已选项和数量。
7. 搜索无结果时提示换词或清空搜索，不提供“创建子系统”。
8. 前端实现时浮层应根据当前行和可用空间上下翻转，避免被表格滚动容器裁切。当前 Figma 浮层固定在第 2 行下方位置用于演示，不是动态锚点定位实现。
9. 真实保存失败时应保留旧值 / 给出可重试提示，不能静默伪装成功；本轮未对接保存接口，也未新增错误状态画面。

## 4. 与标签、导航和 AI 的关系

- 保留“一个业务对象一个标签”的已确认基线；全景是业务功能范围的汇总视图，不是独立业务对象。
- 全景去重键采用设计默认 `projectId + businessFeatureId + panoramaType`；UC 全景和 FR 分配全景分别去重。
- 显示“UC 全景视图 · 儿童锁”“FR 分配全景视图 · 前方碰撞预警”；宽度有限时省略业务功能，正文与完整提示补足归属。
- 点击文件夹名称或其明确的全景入口打开同一汇总标签；展开箭头只展开 / 收起目录，不抢正文焦点。
- 再次打开定位已有标签；切换标签同步工作路径、导航高亮、正文、AI 会话、输入草稿与附件。
- UC 自动生成 / 更新、FR 分配更新不强行打开新标签或抢走当前工作焦点；已打开的全景按所属业务功能刷新。
- 全景 AI 拥有自己的视图会话，不共用任意 UC / FR 对象的会话。UC 全景 AI 可解释用例关系，不能直接改图；FR 分配全景本页只允许下拉修改关系，不通过正文 / AI 绕过只读列约束。

- 13 行子系统框 → 载入该行状态 → 展开候选。
