## 2. 已实现的设计与演示路线

1. 默认界面：保留 64px 顶栏、232px 单侧栏；右侧 1208px 全部用于默认工作区，明确标记产品工程 / PRD生成。
2. 点击输入区或 AEB 示例，模拟填入提示词。空输入的扩写、发送为禁用表现。
3. 点击输入区下方“自动扩写”：紧凑工具按钮；加载图标在文字右侧；短暂等待后直接回填优化文字，停留在输入状态，不自动发送、不出现采纳弹窗。
4. 点击发送：呈现生成中，约 1.1 秒后跳转第二主图。生成后草稿仍待处理，立即显示正文与右侧同一会话。
5. 输出：PRD 作为自由文本预览，章节只是 AEB 示例，并非固定字段；侧栏直接展示功能根目录下的 PRD 对象。
6. AI 回答底部附有悬浮产物卡片：默认勾选本次唯一 PRD；取消勾选时显示已选 0 项并禁用操作；点击接受后更新状态并解锁生成 UC 入口。
7. 点击编辑 → 点击正文功能概述段落，填入预设修改 → 保存/取消。保存仍是待处理，不自动接受。
8. 窄对话框复用相同扩写行为；点击输入区填入驾驶员接管示例，扩写后可发送；发送模拟更新功能概述段落。
9. 放弃有二次确认；确认后隐藏本轮草稿、回到全宽工作区，保留请求内容和上一轮结果摘要。保留空功能目录属于暂定建议。
10. 已接受态可以点击生成 UC，看到已解锁且下一页不在本轮范围的说明；不伪装已生成 UC 数据。
11. 左侧“全部功能 / 功能 / 工作空间”互斥切换。全局导航展示产品工程仅 PRD生成、需求工程仅场景分析 / 功能设计 / 功能分配；其余模块只保留导航外观。
12. 生成失败状态位于输入组件中；演示时在生成中的文字区点击，可切换到失败并重试。这只是检查异常画面的演示触发，不是产品交互约定。
