# marvinzhou.com 一期部署说明

> 目标：用现有域名完成一期可演示部署。本文只覆盖 Next.js 页面、FastAPI 认证和同源 `/api` 代理；不包含 Agent、文件存储和数据库部署。

## 1. 推荐结构

```text
浏览器
  │ https://marvinzhou.com
  ▼
Nginx :443
  │ /                         → Next.js :3000
  │ /api/*                    → Next.js :3000
  ▼
Next.js rewrite
  │ /api/* → http://127.0.0.1:8000/*
  ▼
FastAPI :8000
```

这样浏览器始终只访问 `marvinzhou.com`，HttpOnly Cookie 不需要跨域，前端也不需要把 JWT 放进 `localStorage` 或 `sessionStorage`。

## 2. 阿里云控制台手动操作

1. 创建或确认服务器安全组：开放 `80/tcp` 和 `443/tcp`；`3000`、`8000` 只允许本机访问，不要暴露到公网。
2. 在 DNS 中添加 A 记录：
   - 主机记录 `@` → 服务器公网 IP
   - 如果演示需要 `www`，再添加 `www` → 服务器公网 IP
3. 在阿里云 SSL 证书服务申请或绑定证书，下载 Nginx 格式证书。
4. 将证书文件放到服务器受保护目录，并把 `deploy/nginx/marvinzhou.com.conf.example` 改名为实际 Nginx 配置后启用。
5. 配置完成后先执行 `nginx -t`，再 reload Nginx。

## 3. 后端配置

在 `TS-backend` 创建生产 `.env`（不要提交 Git）：

```dotenv
APP_ENV=production
SECRET_KEY=替换为随机长字符串
DEMO_USERNAME=engineer01
DEMO_PASSWORD=替换为演示密码
CORS_ORIGINS=https://marvinzhou.com,https://www.marvinzhou.com
COOKIE_SECURE=true
COOKIE_SAMESITE=lax
```

当前一期仍使用内存 Demo 用户。正式接入用户数据库前，不要把这个账号当作生产级用户体系。

## 4. 前端配置

在 `TS-frontend` 创建生产环境文件（不要提交 Git）：

```dotenv
NEXT_PUBLIC_API_BASE_URL=/api
NEXT_PUBLIC_USE_MOCKS=false
BACKEND_URL=http://127.0.0.1:8000
```

`BACKEND_URL` 只供 Next.js 服务端 rewrite 使用，不要写成公网后端地址。

## 5. Linux 服务器启动命令

### 后端

```bash
cd /srv/TS-backend
python3.12 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 前端

```bash
cd /srv/TS-frontend
pnpm install --frozen-lockfile
pnpm build
pnpm start -- --hostname 127.0.0.1 --port 3000
```

演示阶段可以先使用两个终端保持进程运行；稳定后再改为 systemd 服务。不要为了第一版演示提前引入 Docker、Kubernetes 或消息队列。

## 6. 部署后的验收清单

- [ ] `https://marvinzhou.com/login` 可以打开
- [ ] 登录成功后进入 `/`
- [ ] 刷新页面仍能通过 `/api/v1/auth/me` 保持登录
- [ ] 退出登录后回到 `/login`

- [ ] `3000` 和 `8000` 没有对公网开放
- [ ] 生产 `.env`、证书和真实密码没有提交到 Git

## 7. 常见问题

### 登录后立即回到登录页

先检查：

1. `BACKEND_URL` 是否为 `http://127.0.0.1:8000`；
2. FastAPI 是否监听 `127.0.0.1:8000`；
3. Nginx 是否把域名请求转发到了 Next.js `3000`；
4. `COOKIE_SECURE=true` 时是否确实通过 HTTPS 访问。

### `/api/docs` 404

确认 Next.js 进程启动时读到了 `BACKEND_URL`，并重新执行了 `pnpm build`。环境变量变化后不能只 reload 浏览器。

### HTTPS 证书错误

先在阿里云确认域名解析已经指向当前服务器，再检查 Nginx 的证书路径和证书覆盖的域名。
