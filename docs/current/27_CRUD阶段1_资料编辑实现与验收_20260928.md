## 1. 本阶段交付

- 功能：沿用已有功能全景标签，顶部资料区查看/原位编辑名称与描述；编号只读；取消编辑/保存修改；不新开功能编辑弹窗。
- 项目：切换项目窗口 → 项目行“⋯” → 查看项目信息 → 编辑项目信息；简介复用description，编号只读。编辑非当前项目不切换项目；修改当前项目同步列表与顶栏。
- 字段：名称去首尾空白后1—100字符，描述/简介选填且最多2000字符；空描述保存为null；不允许改编号、归属或操作者。
- 版本：两个PATCH使用mutation_id（UUIDv4）和字符串base_lock_version；同一请求重放不重复写入或审计；不同内容复用标识/旧版本返回409，输入保留。
- 保存与读取结果区分：无法确认写结果时保留同一操作标识重试；已保存但刷新失败时只重试同步，不再PATCH；表单提交期间锁定并阻止双击。
- 功能资料按稳定ID同步六模块树、标签及上下文；不修改PRD正文，不丢弃其他对象草稿或项目对话；慢速旧workspace响应不能覆盖更高lock_version的资料。
- 内容用语：PRD/UC/FR主动作改为“确认”，保存改为“保存草稿”，状态显示待确认/已确认；内部accept、accepted和/accept不变，保存不自动确认，旧确认版保留。
- 权限：仅接入既有author/reader边界和can_update能力；author可维护非本人创建的对象，不新增权限配置页面或创建人专属限制。

## 2. API与SQL范围

| 接口 | 功能 | 返回 |
|---|---|---|
| PATCH /v1/projects/{project_id} | 修改项目name/description | ProjectRead，含lock_version、can_update |
| PATCH /v1/projects/{project_id}/functions/{function_id} | 修改功能name/description | FunctionRead，含project_id、lock_version、can_update |
| 既有项目列表/详情/workspace | 补充资料编辑能力及功能版本 | 保留既有字段，版本用字符串 |

PATCH未传字段保持原值，description显式null/空白清空；至少提供一个业务字段。认证/Origin/X-Project-Request: 1/JSON防护复用既有机制；404隔离无权访问和不存在，403权限不足，409冲突，422非法输入，503配置/数据库不可用，504锁/查询超时。

事务按项目→功能锁定有效资源，重查权限、并发版本，更新资料与版本并同事务写入既有security_audit_events。审计id复用mutation_id；历史审计不覆盖、不删除。
