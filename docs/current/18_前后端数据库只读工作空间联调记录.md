## 8. 日常调试是否每次都要重复 PowerShell 登录

不需要。

| 操作 | 是否每次重复 |
|---|---|
| 上传数据库授权包 | 只有包版本变化时重复 |
| 6.3 扩展数据库账号权限 | 首次或授权包变更时执行；重复执行会先检查，不应随意重跑 |

| 启动后端 | 后端进程重启时执行；环境变量只对当前窗口/进程有效 |
| 启动前端 | 前端进程重启时执行 |
| 浏览器登录 | 会话过期时重新登录 |
| 查看项目数据 | 登录后直接在页面查看，不需要每次用 PowerShell 调接口 |

PowerShell 的接口脚本只用于故障定位或验证响应，不是日常使用方式。
