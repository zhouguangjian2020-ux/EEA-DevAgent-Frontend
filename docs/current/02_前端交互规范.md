## 1. 维护与范围

- 所有交互变更必须明确入口、作用对象、状态变化、可编辑范围、成功/失败/空状态、键盘行为和持久化边界。
- 变更主规则时原位更新，并在工程记录登记；禁止只在末尾追加与正文相反的“最新要求”。
- 只改用户指定区域；不能参照一张全景 Figma 图就覆盖现有顶栏、侧栏和 PRD / UC / FR 详情。
- Mock 模式是内存态；数据库模式的手动功能/PRD/UC/FR 创建、保存和接受调用真实接口。项目对话、未保存草稿、标签排列仍是浏览器内存态。业务写入需后端配置和项目授权，能力不足时按钮禁用，不能回退成 Mock 成功。

## 2. 标签入口与身份

| 页面 | 入口 | 规则 |
|---|---|---|
| 工作台 | 初始 / 固定标签 | 永久固定最左，不关闭、不排序；横向滚动仍可见 |
| 功能全景 | 任一一级模块工作空间中的功能文件夹名称 | 项目+功能ID唯一；不切换当前模块；顶部显示功能名称/描述及创建PRD入口，原位编辑模式已本地实现，不另开弹窗 |
| PRD | 工作台“生成PRD”保存成功 / 功能全景手动创建成功 / Mock生成成功 | 名称必填，创建为Markdown一级标题；同一功能有未删除PRD时不能重复创建；删后允许新ID创建（已实现）；成功自动打开预览/编辑标签 |
| UC 全景 | UC 文件夹名称 | 打开或激活已有全景，不重复创建 |
| UC 详情 | UC 实例名称 | 单击打开对应对象，已打开则激活 |
| FR 全景 | FR 文件夹名称 | 打开或激活已有全景 |
| FR 详情 | 实例名称 / 全景编号 | 按稳定对象身份打开 |
| FR 分配全景 | FR分配文件夹名称 | 打开或激活已有全景 |
| 子系统详情/编辑 | 待确认 | 不创建假实例、假按钮或自行补全字段和权限 |

- 普通对象使用项目、类型和稳定对象 ID；业务归属仍须包含正确业务功能，不能用显示名称跨功能识别。
- 全景身份为项目 + 业务功能 ID + 全景类型。全景不创建新的需求成果对象。
- 重复打开只激活，不能重建正文或清空聊天。新标签插入当前业务标签旁。
- 工作台的 PRD / 单个 UC 生成成功自动打开并激活新对象，定位对应模块工作空间。后台项目的结果仍归原项目，**不自动把用户从另一项目切回**。
- **单个补充入口**：工作台“用例生成”每次新增 1 个 UC 并自动打开；用于补充批量遗漏，同功能允许多次追加。
- **批量入口**：PRD 详情“生成 UC”直接请求一组用例；Mock 模式仍返回本地演示结果；数据库模式请求生成并原子追加待确认UC，保留已有实例，不自动确认。结果只在当前功能UC目录与独立UC详情展示；PRD页不展示UC候选或结果列表，只显示进度及成功/失败提示。

## 3. 切换、关闭、排序与任务

- 切换标签只切换正文、对象编辑草稿与导航定位；项目对话、聊天草稿、消息、附件和请求不切换。不能把当前标签自动当成聊天操作目标。
- 关闭标签只关闭对象视图；对象、分配关系和项目对话不删除。关闭最后对象回工作台，对话及附件仍保留。
- 未保存正文关闭时提供“保存并关闭 / 不保存并关闭 / 取消”；数据库模式必须等待写入与工作空间同步成功才关闭，失败保留草稿与弹窗；提交期间阻止重复提交、编辑及关闭。保存不等于接受。
- 项目对话任务独立于对象标签；切换/关闭标签不停止项目请求。对话区提供“停止”，停止后迟到结果不得落入对象集合。未接后台任务中心，不能宣称关闭浏览器后继续运行。
- 当前标签关闭后回退最近访问且仍打开的标签；无业务标签时回工作台。关闭非当前标签不切换当前内容。
- 取消或关闭后的迟到结果不得复活已停止任务、覆盖其他对象或重建产物。
- 普通业务/全景标签可排序；工作台不可排序。过多时横向滚动与全部标签搜索，不自动关闭旧标签。
- 键盘：左右切换、Home 到工作台、End 到最后标签、Delete 只关闭当前可关闭标签。

## 4. 顶栏、项目与账户

- 项目选择必须确认才生效，取消不切换。旧项目内存态保留，异步结果仍写回其原项目。
- 2026-09-22：项目切换窗口提供“＋新增项目”。新增项目只填写项目名称（必填，1～100字符）和项目说明（选填，最多2000字符）；编号、ID、创建人和时间由后端生成/记录。点击“创建并进入”后立即进入真实空项目，不复制其他项目数据；项目创建请求使用同一个creation_id重试，不能因超时重复创建。
- 明暗主题切换不改变对象状态、草稿、标签或子系统选择。
- 保留现有账户资料弹窗与头像本地预览；不推导出完整用户管理能力。
- 认证沿用 Cookie 调用；不得把认证 token 存入 localStorage/sessionStorage。主题偏好不属于认证 token。
- 2026-10-02 项目创建链路修复：创建成功及确认切换时将真实项目UUID同步到当前标签页URL的 `project_id`；刷新按该UUID恢复项目，不再无条件切到项目列表第一项。项目不在第一页时按ID鉴权读取；无权访问/已删除/非法ID时明确提示并要求重新选择，临时读取失败时阻止业务操作并允许重试，不得静默切入其他项目。首次没有指定项目的访问仍可按既有规则选择列表第一项。
- 手动创建功能/PRD/UC/FR弹窗显示所属项目名称与编号，PRD等同时显示所属功能。表单目标在打开时固定；若当前项目发生变化，禁止旧表单继续提交，不把输入自动改绑到其他项目。
- 刷新/退出保留离开提醒；数据库已保存正文和接受状态在恢复原项目后重新查询。未保存草稿、对话和标签布局不持久化，不承诺自动恢复。

- 底层保留历史但业务删除不提供恢复；本轮不做已删除列表、恢复按钮/API或永久清空。删除成功后再刷新树、全景及受影响标签；失败保留对象和输入，不影响无关草稿/对话。
- 一个功能最多一份未删除PRD；没有关联UC时可删，删后允许创建全新ID的PRD，不恢复原对象，不复制旧正文或确认状态。阶段2独立增量已同时调整两层唯一约束、后端创建检查和workspace创建资格；前端删除成功后的刷新接线在阶段3完成。
- 功能存在未选中内容则阻止，完整选择且可合法删除后才在批次最后删除功能；单选功能须为空。项目非空禁止删除已确认，不整体移除或隐式级联。权限管理暂缓，保留既有项目级读写边界。

## 10. 工作台与项目对话（2026-09-21 用户已确认）

### 10.1 同一对话，两种布局

- 对话按项目隔离，与对象标签解绑。无活动对象时位于工作台中央；打开对象时同一对话布局为右侧栏，不复制、不清空或重建。
- 项目对话有用户/Agent 消息输出区、滚动历史、输入、附件、结果链接、加载、停止、错误和重试。
- 数据库模式普通问答调用后端私有会话；Mock模式输出模拟回复。问答不创建对象/标签。基于附件的问答仍在此完成；点击附件或结果链接打开对象后，附件和历史继续保留。
- 仅浏览对象不自动引用它，也不让下一句输入自动修改该对象。PRD/UC/FR/全景内部的对象专属聊天已撤出活动 UI；对象编辑与审阅独立保留。
- 同项目切换标签保持聊天草稿；跨项目切换恢复各项目自己的会话、附件、草稿与运行状态。已保存历史由后端恢复，未发送输入仍为内存态。新建/切换会话读取期间临时禁用输入，完成后才恢复目标草稿，避免新输入被迟到的切换结果清空。

### 10.2 快捷生成与互斥（2026-10-08用户纠偏）

- **真实数据库模式必须有PRD生成、用例生成快捷入口**，不能只在Mock分支渲染。PRD生成不弹独立表单：用户在原对话输入框输入需求，点击发送或Ctrl/⌘+Enter，沿同一创建意图完成Agent功能计划→查重→创建/复用功能→生成并保存待确认PRD。
- 点击入口仅改变本地模式，不发Agent请求；不切换或关闭当前中间对象标签。提交后原需求出现在所属会话的内嵌任务中，输入框清空；校验失败保留输入。生成期间新输入的下一条草稿不被完成回调清空。
- 功能名称来自后端验证的plan.feature_name；无候选自动继续；同名/相似候选、显式复用、改名新建、已有PRD只读打开、失败重试及回执查询均在当前会话任务内完成，不新开弹窗。PRD自动保存为待确认，不自动确认。
- 继续复用现有PrdCreationSession，不复制第二套后端流程。客户端任务交互按项目+thread隔离；切换会话后旧任务不出现在新会话，后台结果不抢当前标签。切回原会话可继续本页尚在的任务；刷新浏览器后持久任务记录/已保存对象可恢复，未结束候选交互不承诺自动恢复。
- 每个持久任务仍只有一张系统卡。当前PRD任务的交互嵌入对应client_request_id的卡片；回执尚未到达时先显示内嵌状态，不重复发请求；新功能改名草稿随创建意图保留，任务卡迟到不清空。不伪造普通聊天轮次，不覆盖已有首问标题。
- 真实“用例生成”快捷入口选择当前项目已有且PRD已确认的功能；明确点击“生成UC”复用既有PRD→UC追加接口，不假装支持尚未对齐的“按聊天提示补充单条UC”契约。输入框聊天草稿保留且不随这个批量任务发送。新增为待确认UC，保留旧实例，仅定位/展开左侧UC目录，不切中间标签。
- **Mock模式**保留原模拟PRD/单条UC快捷流程，不宣称是后端能力。数据库模式不注入测试A/B/C功能；无PRD、PRD未确认、正在编辑/生成或无创建资格时禁止UC快捷提交。
- 自动扩写在普通输入和两种快捷模式中仍固定可用，只优化输入，不发送、不创建对象。沿用ONE_CLICK_EXPAND，扩写不依赖UC功能选择。真实普通问答正常发送；不再使用“数据库项目暂不开放发送”的过时文案。
- 选择快捷任务按原显式模式规则移除已选对象附件，提示已移除；真正添加对象到AI对话则取消快捷任务。未手动添加附件时普通聊天发送attachments=[]，不得悄悄附加当前标签内容。仅勾选候选、不发送，不取消模式。
- “开始另一项需求”重置已结束任务并重新选中PRD快捷入口。停止仅停止前端等待，后端可能继续，状态不明时先读回执；失败已绑定功能只能继续原功能。手动创建/保存、已有PRD生成预览、UC/FR/分配的原入口不受影响。

### 10.3 请求、结果与错误

- 本节描述项目对话/Mock 快捷生成；数据库PRD新建以本规范10.2和54号2026-10-08修正为准，真实已有PRD标签页预览以第6.1节为准。对话请求快照包含 projectId、mode、featureId/name、prompt、references；UC 另含已接受 PRD 的 workId、正文和版本。均为本地适配层数据，不声称是已批准的后端 HTTP 格式。
- 一项目同一时间一个对话请求；运行时生成模式、功能、附件添加/移除锁定，提交和扩写禁用；允许继续输入下一条草稿（扩写时输入锁定）。
- 完成后再次校验输入资格和来源版本，防止重复 PRD、过期 PRD 生成 UC或迟到回调覆盖现有对象。
- PRD 成功建立两模块目录及待处理 PRD；UC 成功在既有 UC 分类下新增一个待处理 UC；自动切模块工作空间、清搜索、展开、选中并打开对象。成功后退出快捷模式，保留历史与下一条草稿。
- Mock失败保留输入和请求快照，不创建空目录/对象。真实PRD自动创建若已绑定功能则保留它，重试只继续原功能；停止仅停止前端等待，不能宣称后端未写入。响应丢失只读查回执；已保存但目录失败显示为读取问题而非生成失败。
- 三种输入模式的自动扩写均复用现有Agent接口；普通问答和对象生成的接入范围不变，不做附件自动修改、真实持久化或后台任务恢复。浏览器不携带 Agent Key，统一经业务后端转接。测试选项仍用于模拟发送失败，不会让真实扩写在失败时偷偷回退 Mock。
- Agent 上游实际返回 `text/event-stream` 的逐行 JSON：`token` 事件累计正文，`done` 事件提供完整输出。业务后端消费并校验该流后，向浏览器返回统一的完整结果；逐字回填仍是前端呈现效果，不是浏览器直连 Agent 的原生流。等待期间保留原文，回填期间输入只读，成功后才提交新草稿。停止或失败恢复原文；停止不保证撤销 Agent 已执行的推理。系统减少动态效果开启时直接完整回填。

- 失败、重试、取消有明确状态；关闭对话框不能隐式确认放弃或停止。
- 控件需有可访问名称和可见焦点，只读图形不伪装成按钮。

### 10.5 项目权限与账号管理（2026-09-29 用户确认，本轮首版实现）

- 顶部“项目权限”按钮只在当前项目返回 `can_manage_access=true` 时显示；只有当前项目管理员可以读取和修改该项目的权限设置。项目 A 的成员/功能授权不影响项目 B。

- 功能权限按当前项目内的具体功能选择，角色只有“功能查看者”和“功能编辑者”。功能编辑者包含编辑、工程审查和确认，不再单独设置功能审核者；没有单独功能授权时回退到项目级角色。

- 第一版不做 SSO、LDAP/OIDC、找回密码、自由权限矩阵、显式拒绝规则和复杂组织架构；候选账号使用已有账号列表，保留后续搜索/筛选扩展空间。删除权限仍不能绕过既有业务依赖保护。

## 15. 2026-09-29 Agent 输出格式修订：PRD 正文使用 Markdown

- PRD 正文不是结构化字段集合；Agent 生成 PRD 时，`output` 直接返回完整 Markdown 正文。已有手动保存接口以 `markdown_body` 保存该字符串，不要求 Agent 再包一层 PRD JSON，也不把章节拆成数据库字段。本轮流式生成仅转发 Markdown 到独立预览，不自动调用保存接口。

## 16. 2026-09-29 UC Agent 结构化链路（服务端第一步）
