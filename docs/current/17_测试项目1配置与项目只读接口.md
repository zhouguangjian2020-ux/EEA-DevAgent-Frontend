## 2. 后端项目只读接口

### 2.1 两个GET接口

| 接口 | 作用 |
|---|---|
| `GET /v1/projects?limit=20&offset=0` | 当前登录用户能访问的未归档项目列表 |
| `GET /v1/projects/{project_id}` | 当前登录用户能访问的单项目详情 |

沿用HttpOnly Cookie认证。不接受浏览器传来的subject/user_id作为授权依据；使用现有认证验证过的JWT subject。当前本机配置为`engineer01`，不是`/me`展示名“工程师01”，也不是DBA导入身份`manual:ssh:t7920`。

为当前登录主体新增的业务角色`project_api_reader`只包含`project.read`，仅绑定这一个样本项目。原导入人的只读角色不改。它不是PostgreSQL账号，也没有FR/UC读、编辑或接受权限。功能名及其他数据本次在数据库配置，但**不新增功能/PRD/UC/FR等读取API，也不让前端自动切换Mock**。

以下仅为命令行自动检查保留，不是日常必做。Windows PowerShell 5.1对未显式声明charset的JSON响应可能按错误编码解读；只设置控制台编码不能修复已经解码错误的字符串。此处直接从响应字节按UTF-8解码，不修改数据库或后端JSON协议。

```powershell
$ErrorActionPreference = 'Stop'
function Read-ProjectJsonUtf8 {
  param([string]$Uri, [Microsoft.PowerShell.Commands.WebRequestSession]$Session)
  $Response = Invoke-WebRequest -UseBasicParsing -Uri $Uri -WebSession $Session -ErrorAction Stop
  $Response.RawContentStream.Position = 0
  $Reader = [System.IO.StreamReader]::new($Response.RawContentStream, [System.Text.Encoding]::UTF8, $true)
  try { $Json = $Reader.ReadToEnd() } finally { $Reader.Dispose() }
  $Json | ConvertFrom-Json
}
$SecureLogin = Read-Host '现有engineer01登录密码（不回显）' -AsSecureString
$LoginCredential = [System.Management.Automation.PSCredential]::new('engineer01', $SecureLogin)
$LoginSession = $null
$Body = [System.Text.Encoding]::UTF8.GetBytes((@{ username = 'engineer01'; password = $LoginCredential.GetNetworkCredential().Password } | ConvertTo-Json))
try {
  Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/v1/auth/login' -ContentType 'application/json; charset=utf-8' -Body $Body -SessionVariable LoginSession | Out-Null
  Read-ProjectJsonUtf8 -Uri 'http://127.0.0.1:8000/v1/projects?limit=20&offset=0' -Session $LoginSession | ConvertTo-Json -Depth 6
  Read-ProjectJsonUtf8 -Uri 'http://127.0.0.1:8000/v1/projects/10d4c8a0-ff3a-56c3-abf6-18dc3b531e62' -Session $LoginSession | ConvertTo-Json -Depth 6
} finally {
  try {
    if ($LoginSession) { Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/v1/auth/logout' -WebSession $LoginSession | Out-Null }
  } finally {
    $Body = $null
    $LoginCredential = $null
    $SecureLogin = $null
    $LoginSession = $null
  }
}
```

预期列表/详情返回“测试项目1”。空列表先核对登录subject和业务授权，不能删掉权限过滤。503先核对DSN、隧道、角色密码和权限，不开放5432外网、不改用超级用户。不要把Markdown链接语法`[地址](地址)`复制进URI，只复制代码块中的原始地址。
