## 1. 多选交互

- 侧栏“多选删除”进入独立选择模式；删除选择不复用AI附件选择。分类节点只用于展开/导航，不作为批量删除对象。
- 功能勾选不会自动勾选PRD、UC、FR或FR分配；最多200项；点击“取消”只清除删除草稿，不清除附件选择。
- 同一个FR分配在多个子系统目录下投影时按`FR_ALLOCATION:<allocation_id>`去重；零目标真实分配也可以选择。
- “删除所选”只提交明确选择。弹窗一次列出类型、数量、全部对象、未保存输入和分配全部目标影响。

## 2. 后端批量契约

- 预检查：`POST /v1/projects/{project_id}/deletion-batch/impact`。
- 原子提交：`POST /v1/projects/{project_id}/deletion-batch`。不接受query参数、`force`或`cascade`，不是前端循环调用多个DELETE。
- 批次外活动依赖阻止整批；批次内按`FR_ALLOCATION → FR → UC → PRD → function`处理。项目不能加入对象批次，非空项目仍不能单独删除。
- 提交时重新获取项目锁、功能锁、权限、版本和全部依赖；任一对象冲突、权限不足或出现新外部依赖，整批回滚。
- 同一`mutation_id`按排序无关的规范化请求幂等；请求身份、对象集合或版本不一致时拒绝复用；一条`batch.delete`审计与所有更新共事务。

## 6. 推荐验收矩阵

| 场景 | 预期 |
|---|---|
| PRD被活动UC引用 | 单条预检查阻止，列出UC及原因 |
| UC与其FR一并选择 | 批次内依赖可处理；若存在外部PRD依赖则按外部依赖规则阻止 |
| FR有未选分配 | 批次外依赖阻止FR及整批 |
| FR与分配一并选择 | 批次内按分配先删，FR随后删；FR/子系统目录不被隐式删除 |
| 功能与未选内容 | 批次外内容阻止功能；不自动勾选后代 |
| 功能与全部合法内容 | 同一事务最后删除功能 |
| 网络未知结果 | 弹窗锁定并保留原mutation、对象集合和版本，用户显式重试 |
| 任一版本/权限/审计故障 | 整批不删，选择和未保存输入保留 |
