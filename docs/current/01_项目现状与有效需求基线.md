## 1. 项目在做什么

天枢 EE 智能开发平台面向需求工程工作：以项目组织多个业务功能，以对象独立工作页和项目级 AI 对话协助形成、审阅和追溯 PRD、UC、FR 与子系统分配结果。

```text
项目
  ├─ 业务功能 A
  │    └─ PRD → UC → FR → FR 分配关系
  ├─ 业务功能 B
  │    └─ PRD → UC → FR → FR 分配关系
  └─ 项目级子系统方案（设计方向，供各功能分配引用）
```

箭头表达业务来源链，不代表全部生成接口已接通。全景是对象集合的视图，不是第五类需求成果对象。

## 4. 已统一的业务基线

1. 一个项目包含多个业务功能。每个业务功能对应一个稳定 PRD 对象，版本另行管理。
2. 标签负责正文与编辑；对话、聊天输入草稿、附件和请求绑定项目，不随标签切换。操作目标来自显式模式/功能/引用，不从活动标签推断。
3. PRD 是自由 Markdown / 文本，不因 UI 卡片化而变成固定字段表单或多个审批对象。
4. UC 为 12 个顶层字段；主事件流、4 条分支、5 类异常位于“场景”内部。
5. FR 保留编号、来源、描述。来源设计允许关联多个 UC；正式接口如何表达需以业务后端契约落地。
6. 分配关系独立于 FR 正文，一个 FR 可以选择多个子系统；清空是否允许是当前实现默认而非已确认强制规则。
7. 保存不等于接受；AI 任务完成不等于业务成果已接受；关闭标签不等于删除对象。
8. 项目级子系统方案由 V1.2 修订设计，不再把某张演示清单或固定 43 项写成全局架构约束。
