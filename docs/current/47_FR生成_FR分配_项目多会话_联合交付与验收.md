## 3. 一次人工验收

使用批准的专用项目/功能；先明确完成增量迁移和受控子系统目录初始化，不拿生产项目造测试数据。

1. UC全景生成FR，改文字、只选需要的项并保存；检查编号、待确认和不覆盖已有FR，再到FR页确认。
2. FR分配生成，选多个子系统并改说明，保存后确认；再次编辑保存，检查旧确认版本仍保留。
3. 右侧建立两个会话分别发消息、切换；刷新及退出重登录后选择原会话，历史完整且互不混合。另一用户不能读取这些thread。
4. 从工作空间添加PRD/UC/FR到AI对话，先问答再修改；丢弃一次检查原文不变，再生成并应用为待确认版本，最后到原对象页确认。
5. 生成时停止/模拟断流，检查未完成和原请求重试；未保存候选刷新不要求恢复。
6. 联调台测试新增4项：先创建会话，再填写返回thread_id；检查完整来源、目录、历史/附件版本、response_format及脱敏后的X-API-Key。
