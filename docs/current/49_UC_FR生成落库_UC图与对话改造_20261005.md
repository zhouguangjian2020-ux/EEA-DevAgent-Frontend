## 1. UC图
- 工作空间的功能UC总览打开时自动检查该功能最新已确认UC。来源没变且已有有效图则复用；没有图或来源版本改变则生成。打开单条UC文档不触发总览生成。
- 已打开标签提供刷新UC图按钮；显式刷新按最新已确认UC强制重新生成。未确认UC不进入来源。
- 默认展示真实Mermaid图形，代码可折叠查看；Agent代码必须隔离/严格安全渲染，禁止执行脚本或外链交互。无来源明确显示空状态。
- 失败显示原因并允许重试；已有图保留且标记旧结果/刷新失败，不伪装为最新图。来源、项目、功能切换和过期响应必须隔离。
- 联调接口成功不代表生产前端成功；生产前端连代码不显示的问题纳入诊断和本地回归。

## 2. UC和FR生成后追加待确认实例
- PRD生成UC成功后直接保存为待确认UC；数据库模式UC追加成功后，左侧自动切到需求工程→工作空间，清除搜索并展开当前功能和UC文件夹；中间不切换标签、不自动打开首条UC或UC全景，不增加或重排已打开标签。新实例由用户主动打开后编辑和确认。
- PRD页面不显示UC候选、UC结果列表或UC详情，只保留生成入口、进度和成功/失败提示。
- FR同样改为生成成功直接保存待确认实例；不再要求先人工采纳候选才能创建FR。创建后仍可编辑，正式确认仍是独立人工动作。
- 每次新的生成追加新实例，所有已有实例（含未确认与已确认）均保留；不自动替换、删除或按相似名称合并。相同请求重试必须幂等，不重复创建。
- 使用既有业务鉴权、来源精确版本、不可变修订和创建机制；生成期间来源变化不得将旧结果偷偷关联新来源。非法结果不当成功，落库失败不得只显示成功或遗失已落库状态。
- PRD仍为每功能一份有效实例；聊天修改已有对象产生新版本，不等于追加新对象。分配仍沿用原有草稿与确认闭环。
- 保持联调预览后端BUSINESS_WRITES_ENABLED=false，不为预览开启业务写入；原只读生成契约须保留以兼容联调台。

## 3. 项目对话
- 删除问答/修改操作下拉框，由Agent根据自然语言判断意图；需要修改时返回结构化预览，经用户显式采纳创建新待确认版本，不能自动写回或自动确认。
- 无当前附件时，附件列表为空，对象ID、修订和正文相关字段不填充；不把当前打开对象或历史附件自动作为本次修改目标。
- 保留project_id、后端生成的thread_id、用户隔离历史；当前无附件不等于清空正常历史上下文。后端按当前用户、项目、thread校验归属，再将该thread已存提问/回复放入reference_data.messages，当前问题放message；新thread不继承其他thread历史。100轮或上下文1,500,000 UTF-8字节超限时明确拒绝并提示新建，不静默截断。本地已验证真实路由发给契约Mock的请求体，不将其等同真实公司Skill理解效果。
- 项目对话首次显示时自动请求后端建立并选中新会话，无需先点击新建；同次挂载切换对象标签、隐藏后返回项目不重复创建、不切走已选会话。整页刷新后自动准备新会话，旧会话仍可选择。保留新建按钮供主动另开会话；复用请求幂等键避免StrictMode重放重复创建。
- 下拉显示首个用户问题，不拼接ID；未提问时显示“新会话”。首问归一化空白并最多展示120字符，后续提问不改名。UUID仍由后端生成；列表/历史查询从首条提问投影标题，不改创建时的幂等标题，无需迁移旧会话。
- 修改建议必须绑定当前显式授权附件和精确base_revision_id；Agent输出不得绕过权限、对象归属、修改目标或来源检查。
- 保留真实流式反馈、停止、失败、重试以及修改预览的采纳/丢弃保护；新自动意图契约明确交付给Agent工程师，不假称公司Agent已支持。
