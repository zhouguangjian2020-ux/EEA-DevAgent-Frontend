## 1. 当前服务状态和UC模板只读检查

以下完整指令显示容器状态、检查7000/7018/7200健康，并使用当前主后端内的回调密钥验证UC模板401/200及结构；不输出密钥。不需要上传文件或安装依赖。

```bash
(
    set -euo pipefail
    echo '=== TS container states ==='
    docker ps -a --filter 'name=ts-agent-' --format 'table {{.Names}}  {{.Image}}  {{.Status}}'

    echo '=== service health ==='
    for URL in 'http://192.168.64.3:7000/health' 'http://127.0.0.1:7018/health' 'http://192.168.64.3:7200/health'; do
        echo "CHECK $URL"
        if curl --noproxy '*' -fsS --connect-timeout 3 --max-time 5 "$URL"; then
            echo
        else
            echo "UNREACHABLE_OR_UNHEALTHY: $URL"
        fi
    done

    echo '=== current main backend UC template ==='
    CONTAINER='ts-agent-backend-20261003-workflows-r2'
    EXPECTED='true sha256:4ca6143e223802bc957256f55e78c3f648f3d010208fba2f2171f77df4abb989'
    ACTUAL=$(docker inspect --format '{{.State.Running}} {{.Image}}' "$CONTAINER")
    if [ "$ACTUAL" != "$EXPECTED" ]; then
        echo 'STOP: backend state or image differs; no request sent'
        exit 1
    fi

    docker exec -i "$CONTAINER" python -B - <<'PY'
import sys
import httpx
from app.core.config import settings

key = settings.agent_callback_key.get_secret_value().strip()
if not key:
    print('STOP: AGENT_CALLBACK_KEY is not configured')
    sys.exit(1)

url = 'http://192.168.64.3:7000/v1/agent/uc-template?scene=FROM_PRD_CREATE_UC'
try:
    with httpx.Client(timeout=10.0, trust_env=False, follow_redirects=False) as client:
        missing = client.get(url)
        print('WITHOUT_KEY_HTTP_STATUS=', missing.status_code, sep='')
        response = client.get(url, headers={'X-Agent-Internal-Key': key})
        print('WITH_KEY_HTTP_STATUS=', response.status_code, sep='')
    if missing.status_code != 401 or response.status_code != 200:
        print('UC_TEMPLATE_AUTH_CHECK_FAILED: response bodies withheld')
        sys.exit(1)
    body = response.json()
    if (not isinstance(body, dict)
            or body.get('scene') != 'FROM_PRD_CREATE_UC'
            or not isinstance(body.get('fields'), list)
            or len(body['fields']) != 12
            or not isinstance(body.get('candidate_schema'), dict)):
        print('UC_TEMPLATE_CONTRACT_CHECK_FAILED')
        sys.exit(1)
except (httpx.HTTPError, ValueError) as error:
    print('CHECK_FAILED: ' + type(error).__name__ + '; details withheld')
    sys.exit(1)

print('UC_TEMPLATE_AUTH_OK')
print('READ_ONLY_CHECK_FINISHED: no key printed; no service changes')
PY
)
```

## 3. 模拟登录并测试 UC 生成

先粘贴下面的函数，**只需定义一次**。测试数据为“测试项目1 / 行车记录仪 DVR”。如使用其他授权账号，修改 `UC_USERNAME`。

```bash
run_uc_test() {
  docker exec -it \
    -e UC_API_BASE_URL=http://192.168.64.3:7000 \
    -e UC_ORIGIN=http://192.168.64.3:7100 \
    -e UC_USERNAME=engineer01 \
    -e UC_PROJECT_ID=10d4c8a0-ff3a-56c3-abf6-18dc3b531e62 \
    -e UC_FUNCTION_ID=29fe01ea-f727-58cf-a326-b75294ba4dbb \
    -e UC_PRD_ID=f6ce553b-d937-5bf6-9933-0ef7905b45f0 \
    -e UC_PRD_REVISION_ID=70449ce3-cf7b-5ca8-b067-26a11e29ce74 \
    -e UC_RUN_GENERATION="$1" \
    -e UC_RUN_DIAGRAM="$2" \
    "$B" \
    env -u UC_PASSWORD -u UC_KNOWN_UC_SOURCE_VERSION \
    python /app/tools/simulate_uc_requests.py
}
```

然后执行：

```bash
run_uc_test 1 0
```

提示 `UC_PASSWORD` 时，输入 **engineer01 的登录密码，不是 API Key**。密码隐藏输入，脚本自动保留登录 Cookie。

先看到以下内容，表示登录和会话正常：

```text
LOGIN_OK user=engineer01
SESSION_OK username=engineer01
```

随后测试 `POST /v1/agent/generations`：

- Skill 接好后，预期 HTTP 200、`status=succeeded`、`candidates` 非空；只返回候选，不自动保存/确认。
- 当前 Skill 尚未完成，且现网场景配置为 `text`、后端要求 `json`，仍可能返回 `502 / agent_upstream_rejected`。**这不是生成成功，也不等于后端进程故障。**
- 若返回 `409 / prd_revision_not_current`，请负责人提供当前已确认 PRD 版本，更新 `UC_PRD_REVISION_ID`；不要为了测试自动修改数据。

## 4. 单独测试 UC 图

即使上一步生成失败，也单独执行本步：

```bash
run_uc_test 0 1
```

再次隐藏输入登录密码，测试 `POST /v1/agent/uc-diagram`。

| 结果 | 含义 |
|---|---|
| `status=empty` | 当前功能没有有效已确认 UC；正常返回，不调用 Agent |
| `502 / agent_upstream_rejected` | 已走到上游，但 Agent 拒绝请求；记录错误，等待 Skill／契约对齐 |
| `status=succeeded` | 已收到并解析 UC 图结果 |

UC 生成结果只是候选，不自动成为已确认 UC，因此图接口返回 `empty` 不一定是问题。两项测试分开运行，避免前一项失败使后一项没有执行。
