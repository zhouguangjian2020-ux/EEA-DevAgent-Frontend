> 日期：2026-09-28（Asia/Shanghai）

## 1. 本阶段完成

1. 工作空间侧栏真实对象行提供“⋯ → 删除”入口：功能、PRD、UC、FR、FR分配均从侧栏发起；分类文件夹不是删除对象。项目删除仍在项目切换窗口单独进行，不混入对象批次。
2. 删除前读取 deletion-impact：显示依赖对象、当前工作版/当前确认版引用和权限结果；被活动下游依赖时禁止删除，失败不提前移除树节点。
3. FR删除检查未删除FR分配对象，不只检查子系统数量；零目标分配同样阻止FR删除。分配删除只删除分配关系，不删除FR和项目子系统目录。
4. 真实FR分配使用数据库allocation ID。一个分配被多个子系统目录投影时，单条菜单和选择集合按真实ID去重；没有目标的真实分配显示“未选择子系统”组。
5. 删除分配后重新读取工作空间：没有任何有效FR关联的子系统组隐藏；仍有其他FR关联的组保留。被删除对象的标签、AI附件和本地缓存同步清理；无关项目草稿和对话保留。
6. 补齐删除成功但刷新失败、慢旧快照、项目删除后隐藏缓存和重新加载入口的保护；慢响应不能复活删除对象。
