- **待确认 / 未验证**：没有充分证据；保留问题，不用猜测填补。

事实判断按“本次用户确认的部署状态 / 本地源码 / 可复查测试记录”分开取证；需求优先级为：用户最新明确要求 > 本目录已确认规则 > 本目录实现默认 > 历史设计。未来实现与需求不一致时记录差异，不以代码自动覆盖需求。
